# Демонстрация Meetora

1. Открыть https://meetorabelikeai-xnsl493w7.gobrev.dev/ и войти своим кодом приложения.
2. Выбрать «Совещание №1 — проверка качества». Это отдельная обработанная запись; исходная сохранена для сравнения.
3. Показать поручения, исполнителей, исходные формулировки сроков и переход к подтверждающим репликам/аудио.
4. Показать ручное уточнение одного поля. Предполагаемое имя голоса требует подтверждения; оно не является распознаванием личности по биометрии.
5. Скачать PDF и DOCX. В PDF поручения собраны в таблицу, далее идёт транскрипт.
6. Новую загрузку демонстрировать с учётом времени обработки: проверка полноты и отдельных карточек требует нескольких минут. Уже обработанную запись представлять именно как готовый результат предыдущего запуска.

Все три модели выполняются на GPU-сервере Brev из локально скачанных весов. Во время инференса внешние облачные API распознавания/LLM не используются. Интернет нужен браузеру для доступа к серверу; это не означает полностью автономную работу ноутбука.

Не заявлять 95%/100% точности по успешному статусу, числу задач или программным тестам. Проверка всех реплик измеряет охват обработки. Для качества нужны отдельные показатели: пропущенные/лишние действия, правильные исполнители, сроки и условия, точность расшифровки и разделения голосов. Эталонный PDF не подставляется в запросы к модели.

Перед выступлением проверить здоровье сервера `/api/health`, доступ к готовой записи, воспроизведение аудио и оба экспорта. Не перезапускать сервер и не запускать второй GPU-процесс во время демонстрации.
